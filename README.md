# Casa Âmbar

Demonstração de cafeteria fictícia com identidade visual, ilustrações em SVG e CSS, filtros de cardápio e reserva simulada. Produtos, preços, história e horários são ilustrativos. Nenhuma reserva, pedido ou pagamento real é processado.

Projeto de Pedro Tiago desenvolvido com apoio de IA.

[Experimentar demonstração](https://pedro-tiago-sites.sabedoriameditativa.chatgpt.site/demo/casa-ambar/) · [Portfólio](https://github.com/sabedoriameditativa-ops/pedro-tiago-portfolio)

## Executar localmente

Com Python 3 instalado, execute nesta pasta:

```sh
python3 -m http.server 8000
```

Abra `http://localhost:8000`. Não há dependências de build para instalar.
